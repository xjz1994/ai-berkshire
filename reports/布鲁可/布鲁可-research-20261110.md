## 0. 信息丰富度评级与AI研究局限

**评级：B级（信息适中）**

| 判定维度 | 情况 |
|---------|------|
| 上市时间 | 2025年1月10日，不足2年 |
| 卖方覆盖 | 有限（花旗、中金、另有1家中性评级机构），目标价88/90/72.4港元 |
| 财务历史 | 仅2021–2026H1六个报告期，且2021–2024受优先股公允价值变动扭曲 |
| 分部数据 | 公司中报/年报披露较细，但海外分国家的完整数据未公开 |

**AI研究陷阱（本报告已针对性规避）**：
- 陷阱一：把"资料多"误当"确定性高"。布鲁可资料量不小，但**只有1年半的公开上市历史**，几乎所有增长数据都来自同一轮周期，无法区分"能力"和"周期红利"。
- 陷阱二：用推算填补空白。本报告对所有推算值标注了口径与置信度，未标注的均为原始披露数据。
- 陷阱三：与市场共识雷同。市场共识是"海外高增+平价拉新"，本报告的重点放在**共识没说的三件事**：国内核心品类只增长2%、单件毛利降11.4%、毛利率三连降与SKU扩张的因果链。

**偏见自查**：
- 如果把资料量减少一半，结论会变吗？——不会。核心判断（海外驱动增长、平价拉低毛利、IP非独家）都来自一手财报数字，不依赖媒体报道。
- 是否存在"公开资料少所以看空"的偏差？——已刻意拉出正面证据：5年累计自由现金流为正、经营现金流/净利>1、零有息负债、上市后持续回购。

## 2. 生意本质 — 段永平"对的生意"

### 2.1 一句话定义

**布鲁可是一家把"授权IP"包装成"平价可拼搭收集品"的供应链型消费公司，靠上新速度×SKU宽度×价格带覆盖赚钱，不靠IP所有权赚钱。**

### 2.2 商业模式画布

| 要素 | 布鲁可的答案 |
|------|------------|
| 客户是谁 | 中国低线城市儿童与家长（9.9元引流款）+ 国内外青少年/成人收藏玩家（39元以上） |
| 为什么付钱 | 正版IP（奥特曼、变形金刚、火影忍者）+ 正版授权下的低价（乐高同题材价格的数分之一） |
| 复购驱动 | **新品驱动**，不是习惯或锁定。2025年新SKU贡献68.6%收入 |
| 收入性质 | 一次性商品销售，无订阅、无平台抽成、无会员费 |
| 上游 | IP授权方（约50个IP，**均非独家**）、模具、注塑产能 |
| 下游 | 经销为主，海内外KA与电商 |
| 资本密度 | 中：模具是主要资本开支（2025年新增2.06亿，账面净值2.69亿），按3年折旧 |

### 2.3 经营杠杆分析

2026H1：收入+32.7%，销售成本+43.3%，销售费用+20.9%，研发+2%，管理费（未单独披露）。
- **成本端有负杠杆**：收入每增1元，销售成本增1.31元
- **费用端有正杠杆**：销售费用率、研发费用率（9.6%→7.4%）都在摊薄
- 净效果：经营利润率仍在扩张（经调整净利率23.9%→22.6%实际是下降的）。**费用效率的改善没能抵掉毛利的侵蚀。**

### 2.4 毛利率为什么是44%而不是乐高的70%

| 公司 | 毛利率 | 差异来源 |
|------|--------|---------|
| 乐高 | 未披露（集团营业利润率26%） | 自有IP、全球定价权、50年品牌 |
| 泡泡玛特 | 69.7%（2026H1） | 自有IP（LABUBU等）、无授权金、盲盒溢价 |
| **布鲁可** | **44.3%** | **必须支付IP授权金；产品同质化；以9.9元主动下探** |
| 奇妙积木/森宝等 | 未披露 | 同一商业模式，同一IP池 |

**44.3%的毛利率结构里，藏着这门生意的本质**：IP是租来的，租金刚性；产品是拼出来的，工艺可复制；价格是自己打下来的。三个环节都不在自己手里。

### 2.5 段永平式追问

> **"这门生意好在哪？"**

好在两点：需求真实（中国潮玩市场2025年879.7亿元、+21%，首次超过传统玩具），和周转极快（应收账款周转6.8天、存货周转2.6天）。

**但段永平真正会问的是**："十年后这家公司还在卖什么？" 如果答案是"还在卖别人的IP"，那这门生意的关键变量就不在自己手上。

## 3. 护城河评估 — 巴菲特"经济护城河"

| 护城河类型 | 是否存在 | 证据 | 强度 |
|-----------|---------|------|------|
| 品牌/定价权 | ❌ 弱 | 单件毛利-11.4%，公司自降价格带至9.9元；毛利率三连降52.6→46.8→44.3 | ★★ |
| 转换成本 | ❌ 极低 | 积木件不通用但可替代，切换品牌成本≈0；收集癖提供弱情感粘性 | ★ |
| 网络效应 | ❌ 几乎没有 | BFC社区（布鲁可粉丝社区）有雏形，但用户增加不改善产品 | ★ |
| 规模效应 | ✅ 是中等的 | 模具/授权费摊薄、注塑产能、全球KA渠道议价。9.9元能赚钱靠的就是这个 | ★★★ |
| 技术/专利壁垒 | ❌ 无 | 模具是资本开支不是技术；高精度多腔模具可采购 | ★ |

### 3.1 护城河趋势：过去3年在变宽还是在变窄？

**结构上变宽，单位经济上变窄。**
- 变宽的部分：渠道（进入美国主流KA）、品类（从积木人扩到积木车）、规模（收入从3.3亿到29亿，授权谈判力提升）。华泰调研指出"奥特曼的积木人授权正在向少数品牌集中"，对布鲁可是利好。
- 变窄的部分：单件毛利、毛利率、净利率全部下行；SKU从682个膨胀到1,851个，说明**要靠不断出新品来维持收入，而不是靠老品复购**。

**这是典型的"规模护城河"——它保护的是成本地位，不保护价格。** 成本地位能让你在价格战中活下来，但不能让你提价。

### 3.2 巴菲特式追问

> **"10年后这条护城河还在吗？什么能摧毁它？"**

10年后规模效应大概率还在（中国供应链+全球渠道不是短期能复制的）。能摧毁它的只有一件事：**IP授权不再续给布鲁可**。约50个IP全部非独家，这意味着任何一个IP方都可以再授权给奇妙积木、森宝、卡游，甚至乐高。护城河的钥匙在别人口袋里。

| 类比对象 | 相似点 | 结局 |

### 4.3 偏误自查

| 偏误 | 本报告的风险点 | 处理 |
|------|--------------|------|
| 叙事偏差 | "潮玩出海"是2026年最热叙事，容易把行业beta当成公司alpha | 已用"国内核心品类+2%"这个数字做对冲 |
| 锚定效应 | 198港元的历史高点、60.35的发行价都是强锚 | 全文估值只用前瞻EPS和自由现金流，不用历史股价 |
| 幸存者偏差 | 只看到海外+228%，没看到这是**第一个**海外完整半年 | 已在置信度部分标注 |
| 近期偏误 | 10月22日-21%的大跌容易诱发"便宜了"的判断 | 三情景估值显示中性IRR仅14%，不便宜 |

### 4.4 空方核心论点（按杀伤力排序）

1. **「这不是IP公司，是给IP方打工的工厂」** —— 50个IP全非独家，授权金刚性，毛利率天花板已现（44.3% vs 泡泡玛特69.7%）。
2. **「增长已经不在主战场」** —— 国内核心品类只增2%，增量靠海外第一次铺货和9.9元降价，两者都是一次性的。
3. **「利润在增长，盈利能力在下降」** —— 净利率21.8%没跌是因为费用率优化，但毛利率-4.1pp、单件毛利-11.4%、折旧占收入从5.3%到8.5%，这三条线终会传导到净利率。
4. **「大股东在卖」** —— 创始人朱伟松2017–2018年减持游族套现超10亿，2024年4月Pre-IPO套现7584万（被证监会问询定价），2026年10月减持2.51亿。**这是一条连续19年的行为记录。**

### 4.5 芒格式追问

> **"我最可能在哪里犯错？聪明人为什么会不买？"**

我最可能犯错的地方是：**把2026年上半年海外+228.5%当成能力，而它可能只是"第一次铺货"的基数效应。** 历史上所有出海第一年的增速都会在第二年腰斩。

聪明人不买的理由很干净：**同一条赛道上，泡泡玛特PE 13.1x、毛利率69.7%、有自有IP；布鲁可PE 15.4x、毛利率44.3%、IP全是租的。凭什么布鲁可比泡泡玛特贵？**

## 6. 行业与文明趋势 — 李录"文明演进框架"

### 6.1 是否是文明级范式转移？

**不是。** 拼搭玩具是19世纪的发明（乐高1932年），潮玩是20世纪末的消费现象。这是**消费结构迁移**，不是文明范式转移。

### 6.2 行业数据

|------|------|------|
| 2025年中国潮玩市场规模 | 879.7亿元，+21%，首次超过传统玩具 | 广东省玩具协会 |
| 乐高2026H1营收 | 419亿丹麦克朗，+21% | 乐高集团 |

| 美国18岁以上玩具消费H1增速 | +25% | Circana（华泰引用） |

**行业结论**：赛道真实、增长真实，而且2026年的增长引擎已从中国转向欧美（成人化+IP大年）。华泰认为"2027–28年是授权IP玩具出海的关键验证期"。

### 6.3 布鲁可在价值链中的位置

```
IP所有方（圆谷/孩之宝/集英社） → 【布鲁可：授权 + 设计 + 模具 + 供应链 + 渠道】 → 消费者
              ↑ 拿走授权金                      ↑ 拿走制造+品牌溢价（薄）
```

布鲁可卡在中间的"制造+分销"环节。这个位置的特点是：**规模可以做很大，利润率被上下游两头挤，估值天花板低。**

### 6.4 客户/供应商集中度

- **供应商**：IP授权方高度集中（奥特曼系列若占比过高，单一IP风险极大；公司未披露单一IP收入占比 — **这是重要的数据缺口**）
- **客户**：以经销为主，单一客户依赖度不高
- **地区**：海外前两大市场是美国和印尼，单一市场风险开始积累

### 6.5 李录式追问

> **"站在20年后回看，布鲁可是这个时代的'标准石油'还是'昙花一现的3Com'？"**

都不是。更接近的类比是**"这个时代的万代中国代工厂 + 半个品牌"**。

真正的分水岭只有一个：**布鲁可能不能把自己的IP做出来。** 如果未来5年自有IP收入占比从现在的可忽略水平提到20%以上，它就有机会向"万代"演化；如果十年后还在卖奥特曼和变形金刚，它就是一家优秀的制造业公司，值10–15倍PE。

### 9.2 一句话区分

**AI分析置信度取决于资料量，投资确定性取决于生意本质。**

本报告对"布鲁可过去18个月发生了什么"置信度很高（一手数据、多源验证、工具验算）。
对"布鲁可未来3年会发生什么"置信度中等（三情景假设透明但无法证伪）。
对"布鲁可10年后还在不在"置信度低——因为答案取决于一份我们看不到的IP授权合同。

**真正决定这笔投资成败的变量，恰好是本报告数据最薄弱的环节。**

### 9.3 需要一手验证的问题清单

1. **奥特曼、变形金刚的授权合同哪一年到期？最低保底授权金是多少？续约条件有没有排他条款？** —— 这一条比本文所有财务分析都重要。
2. **9.9元产品的用户，6个月后的累计客单价是多少？向39元以上产品的转化率是多少？** —— 公司披露"60%是新用户、复购率超70%"，但没有披露向上转化的金额数据。
3. **去三四线城市经销商处看库存周转天数**，验证"上新驱动"是不是把货压给了渠道。
4. **在美国Amazon/Walmart看布鲁可产品的评论数与复购率**，验证海外+228%是真实终端动销还是首次铺货。
5. **模具按3年折旧，产品实际生命周期是多久？** 折旧年限短于产品寿命 = 隐藏利润；长于产品寿命 = 虚增利润。
6. **奥特曼系列占公司收入的比例是多少？** 单一IP依赖度是最大未知数。
