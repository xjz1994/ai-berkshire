## 前置步骤：AI研究偏见自觉

### 信息丰富度评级：A级（信息充裕）

农业银行是A+H两地上市的国有大行，覆盖数据极多：六大行横向对比、券商深度覆盖、监管数据密集披露、历史估值区间明确。属于典型的**A级（信息充裕）**标的。

**AI研究陷阱与应对**：

| 陷阱 | 应对 |
|------|------|
| **共识过强**：高股息、中特估、汇金增持已是市场共识，AI输出易趋同于市场定价 | 本报告重点做**反面检验**：聪明人为什么做空/减持？2026年以来农行回调15-17%说明什么？ |

| **叙事偏差**："县域金融护城河""A股一哥""中特估重估"等叙事可能过度美化 | 逐一检验叙事背后的数据支撑与反面证据 |

## 第二步：生意本质分析 — 段永平"对的生意"

### 一句话定义

**农业银行是中国存款网络最深的零售吸收器——通过1.29万个县域网点+2.28万个境内营业网点吸收全国最便宜稳定的存款，转化为对公与三农贷款，赚取利差，且附带国家信用担保。**

### 生意本质拆解

| 维度 | 分析 |
|------|------|
| 商业模式 | 典型**息差生意**：吸储（负债端）+放贷/投资（资产端）。不是软件、不是平台、不是品牌消费品 |
| 收入结构 | 利息净收入占78.5%，是纯正的利率敞口生意 |
| 复购/粘性 | **存款天然高粘性**——居民把工资、养老、补贴存在四大行，迁移成本高（习惯+网点+信任） |
| 资本需求 | **重资本生意**：靠资本充足率约束扩张，ROE被杠杆和监管双重压制 |
| 经营杠杆 | 银行是天然高经营杠杆：固定成本高（网点/人力/IT），营收小幅波动→利润大幅波动 |

### 5年盈利能力趋势

```
ROE：11.57% → 11.29% → 10.91% → 10.46% → 10.16%  （5年下行，但降幅收窄）
净息差：2.12% → 1.90% → 1.60% → 1.42% → 1.28%   （持续下行，2026Q1企稳于1.26%）
净利：2,412 → 2,592 → 2,694 → 2,821 → 2,910亿   （5年持续正增长，+20.7%累计）
```

**趋势解读**：净息差5年腰斩（2.12%→1.28%），但净利润5年仍增长20.7%——靠**"以量补价"**（贷款规模扩张）+**资产质量改善**（不良率1.43%→1.27%）+**非息收入增长**（代理业务+87.8%）对冲。这种"低息差+高增长"的韧性是农行区别于其他大行的核心特征。

### 段永平式追问

> **这门生意好在哪？**

好在**负债端无与伦比**——全国最多县域网点的存款网络，让农行能以低于同业的成本吸收存款，在息差下行周期中保持相对韧性。县域金融使其天然规避了城商行/股份行的同质化内卷，有"供给侧差异化"。

> **但另一方面（反面）**：好生意不等于好投资。这门生意的利润率被监管定价（LPR/存款利率）、资本约束、政治任务（普惠让利、县域支持）三重压制，ROE长期向下，**净息差可能继续缓慢下行**，利润增长依赖规模扩张——而规模扩张需要资本，资本需要注资或分红留存，形成"越增长越缺资本"的循环。2026年即将到来的特别国债注资（约1500亿）正是这个循环的注脚。

## 第三步：护城河评估 — 巴菲特"经济护城河"

### 五类护城河逐项验证

| 护城河类型 | 验证 | 评级 |
|-----------|------|------|
| **牌照/准入壁垒** | 全国性商业银行牌照极稀缺，国有大行格局20年稳定 | ★★★★★ |
| **网络/网点效应** | 境内网点2.28万个，其中县域网点1.29万个（占56.7%），县域覆盖率同业第一 | ★★★★★ |
| **转换成本** | 存款/贷款客户迁移成本高（对公结算系统、代发工资、政府账户） | ★★★★☆ |
| **成本优势（负债端）** | 县域存款成本低，存款定期化率管理优于同业；吸储成本1.34%（2025年，-29BP） | ★★★★☆ |
| **品牌/国家信用** | "农行"=国家信用，破产风险趋近于零，这是最强的隐性护城河 | ★★★★★ |

### 护城河趋势

**过去5年**：护城河**略微变宽**——县域金融从"蓝海"变"红海"（工行等下沉竞争），但农行的县域网点密度和存量客户仍是难以复制的资产；不良率持续下降验证了其风控能力。

**未来5年预判**：县域金融竞争加剧（工行反超农行市值的事件性标志），**护城河可能从"独一无二"收窄为"领先但需守"**。净息差的绝对水平仍会缓慢下行，但农行相对同业仍保有一定息差韧性。

### 巴菲特式追问

> **10年后这条护城河还在吗？什么能摧毁它？**

**还在**——10年后农行仍是中国六大行之一，仍掌握全国最深的县域存款网络，国家信用仍在。银行牌照+网点+存款粘性的组合，10年维度极难被摧毁。

**能摧毁它的**：①数字化彻底改变存款行为（如果存款从"网点粘性"变成"App价格战"，农行网点优势反而成为高成本负担）；②县域资产质量系统性恶化（三农贷款不良率失控）；③利率市场化极端化导致息差无法覆盖风险成本。三者目前均未发生，但①是5-10年维度的真实威胁——**这也是市场给银行股低PB的长期理由**。

## 第四步：逆向思考与风险清单 — 芒格"反过来想"

### 农行可能失败的所有路径

| 失败路径 | 概率 | 影响程度 | 证据 |
|---------|------|---------|------|
| 净息差跌破1%以下并持续 | 中（30%） | 高 | 2026Q1已降至1.26%，若LPR再降+存款利率下调滞后，息差可能继续下探 |
| 县域/三农贷款不良率失控 | 低-中（15%） | 高 | 县域贷款占41%，个人经营贷质量波动（管理层已坦言"普惠风险是世界性难题"） |
| 房地产链风险再度恶化 | 低（10%） | 中高 | 个人住房贷款4.82万亿在减少，对公房地产逆势增长8,743亿 |
| 地方债务隐性风险 | 低（10%） | 中 | 管理层称"严守不新增隐性债务底线"，但城投敞口仍存 |
| 资本充足率制约增长 | 中（已发生） | 中 | 2026年注资1500亿+永续债200亿，Q3末落地，摊薄EPS约6% |
| 数字化转型落后 | 中（30%） | 中 | 传统网点优势在数字银行时代可能成为包袱 |

### 历史类比

**相似位置的历史公司**：
- **日本大银行（1990s）**：同样是国家队、同样高存款规模、同样依赖息差。日本银行因为资产泡沫破裂+息差崩盘，PB长期0.3-0.5倍，20年不涨。—— **类比警示**：如果中国出现系统性资产问题，银行股的低估不是机会而是"价值陷阱"。
- **2008年美国花旗/富国**：大而不倒，但估值崩了80%。—— 类比提示：国家信用担保≠估值不跌。

**与当前的区别**：中国银行资产质量指标（不良率1.27%、拨备293%）处于历史最好水平，且政府主动注资（3000亿特别国债）而非被动救助，说明**政策层正在用"看得见的手"稳定银行体系**——这区别于日本当年的被动局面。

### 空方核心论点

1. **增长陷阱**：营收增速已降到个位数（2025年+2.08%），净利增速靠拨备释放/非息收入支撑，不可持续。
2. **ROE长期向下**：10.16%且逐年下行，PB重估到1倍的逻辑根基（ROE>10%）正在被侵蚀。
3. **注资摊薄**：2026年3000亿注资（农行约1500亿）虽然补充资本，但摊薄EPS约6%，且暗示"内生资本不足"。
4. **估值已修复**：PB从0.5→0.86倍，中特估逻辑已price in，股息率3.64%（A股）对险资已无超额吸引力。
5. **2026年股价已回调15-17%**：说明聪明钱在高位兑现，"A股一哥"的市值冠军叙事是出货而非建仓。

### 芒格式追问

> **我最可能在哪里犯错？聪明人为什么会不买/做空这家公司？**

**我可能犯的错误**：把"国家信用担保"误认为"投资安全边际"。国家担保保证的是**不破产**，不是**股价不跌**——日本银行就是证明。农行从0.5倍PB涨到0.86倍，赚的是估值修复的钱；如果高股息资金的边际购买力耗尽，股价可能回到增长逻辑定价（更低PB）。

## 第六步：行业与文明趋势 — 李录"文明演进框架"

### 是否处于文明级范式转移？

**银行不是，但银行所处的资金环境正在范式转移。**

| 维度 | 分析 |
|------|------|
| 技术革命类比 | 银行不是蒸汽机/电力/互联网/AI级别的变革者，而是**基础设施的受益者与承压者**。AI时代的金融脱媒+数字支付（支付宝/微信/数字人民币）正在侵蚀银行支付结算的中间环节 |
| TAM（总可寻址市场） | 中国银行业总资产约400万亿，增长趋缓（信贷增速从双位数降至个位数），TAM接近饱和 |
| 产业价值链位置 | 农行在信贷价值链的中游，上游是存款（吸储），下游是贷款（放贷）。**在资金充裕（M2高、存款多）但需求不足（企业投资弱）的环境下，息差被双向压缩** |
| 技术路线风险 | 数字人民币+开放银行+央行数字货币可能重塑支付和存款格局；农行的IT投入（百亿级）能否跟上互联网系对手存疑 |
| 客户集中度 | 极度分散（县域农户+中小企业+个人储户），无单一客户依赖，这是优势 |

### 20年维度判断

> **站在20年后回看，农行是"这个时代的标准石油"还是"昙花一现的3Com"？**

**更接近"标准石油"**——基础设施型生意，20年后中国仍需要全国性存款吸收和信贷投放体系，农行的牌照和网络不会消失。**但"标准石油"不等于好投资**：标准石油之后是被反垄断拆分+石油危机时代。银行的宿命是**持续被监管、被让利、被当成政策工具**。

**李录式追问**：如果中国未来20年GDP增速从5%降到3%，信贷增速降到6-7%，农行的利润增长靠什么？答案只能是：**资产质量改善（信用成本下降）+非息收入（财富管理）+存量重定价（息差企稳）**。这三个引擎都有天花板。20年后农行可能依然庞大，但可能以"中国式高股息公用事业股"的形态存在——低增长、高分红、低估值。这未必是坏投资，但绝不是一个"成长故事"。
