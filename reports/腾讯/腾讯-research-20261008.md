## AI研究偏见自觉

**信息丰富度评级：A级（信息充裕）**

腾讯是全球卖方覆盖最密的公司之一。A级的核心陷阱是**共识过强、AI输出与市场定价高度雷同，alpha趋近于零**。

**本期出现的A级陷阱，比上期更严重，且是本报告自身的错误。**

上期报告（10/5）用整整一节分析"混元的AI竞争力"，结论是"入口强、模型弱"，并把 DeepSeek 列在**竞争对手**一栏（"DeepSeek：V4.1 Flash，年化营收突破10亿美元，API毛利率82.9%"）。**上期报告完全不知道腾讯在6月已经出资约100亿元入股了 DeepSeek，更不知道腾讯正在领投它的第二轮。**

**这个错误是怎么发生的？** 因为它符合当时已经形成的叙事框架——"混元调用量排名下滑 → 腾讯AI掉队"。在这个框架下，DeepSeek 只能是竞争者，不可能是腾讯的资产。**这正是A级陷阱的教科书案例：资料越多，越容易沿着已形成的叙事挑选证据，而漏掉框架之外的事实。**

**反制措施（本期执行）**：
- 对每一条"负面AI证据"追问一句：**"有没有可能腾讯是通过另一条路径参与的？"**
- 特别检查腾讯的**投资组合**而非只看**自研产品**——腾讯历史上最擅长的从来不是自己做，而是投。

**偏见自查清单**：
- [x] **我的"确定性"来自生意本质还是资料数量？** → 核心财务是高确定性；但"混元竞争力"的判断，本期被证明是**建立在残缺事实上的低置信度推理**
- [x] **如果把资料量减半，结论会变吗？** → 估值结论不变；但"AI掉队"的判断会**完全翻转**。这暴露了该判断的脆弱性
- [x] **AI输出是否与市场共识雷同？** → **高度雷同**。市场共识（"腾讯AI落后"）与本报告上期结论一致。**本期必须警惕：当AI和市场想的一样时，alpha在哪里？**
- [x] **是否存在"公开资料少但生意本质好"的可能被低估？** → 腾讯属A级，不存在此问题。但本期教训是：**A级信息下，漏掉的不是"少的信息"，而是"框架外的信息"**

**多方解读（"腾讯的投资版图战略在AI上重演"）**：

2. **这解释了此前几处"矛盾"的观察**：上期报告困惑于"为什么微信'小微'用WeLM而非混元"——**如果腾讯本身是DeepSeek的股东，那么"不绑定自家混元"就不是能力问题，而是刻意的多模型策略。**
3. **可量化的财务含义**：首轮出资约100亿元，对应估值约4,000亿元；第二轮投前估值5,000亿元。**若DeepSeek于2027年初IPO，这将是一笔类似燧原科技的价值兑现事件**——且规模更大（DeepSeek估值5,000亿元 vs 燧原上市首日约1,700亿元）。
4. **DeepSeek的经营数据是硬的**：ARR超10亿美元、毛利率82.9%（高于Anthropic/OpenAI）、提价2.3–4.5倍未流失客户。**这是中国AI模型公司中最好的商业验证之一。**

**空方解读（"这是一张承认自研落后的收据"）**：
1. **如果腾讯相信混元能赢，为什么要花100亿元买竞争对手？** 上期报告已确认混元在 OpenRouter 的调用量排名四周内从第3跌至第5（环比-32%）。**这笔投资可以被读作管理层对自研路线投下的不信任票。**
2. **利益冲突**：DeepSeek 的成功会**直接蚕食**混元的份额。腾讯同时是两个竞争者的股东和一方的主人。
3. **没有控制权**：据每日经济新闻，外部投资方的资金进入梁文锋管理的有限合伙，**不享有投票权**。**腾讯买的是财务回报，不是战略协同。** 这笔钱**不能保证**腾讯获得 DeepSeek 的模型、算力或优先合作权。
4. **金额相对于AI资本开支很小**：100亿元（首轮）相对腾讯年化约1,700亿元的资本开支，占比约6%。**它不是"战略转向"，只是一笔财务投资。**

> **本报告的判断（明确标注为观点）**：**多方解读更有说服力，但空方的第3点（没有控制权）被市场严重低估。**
>
> 理由：腾讯的投资史证明这是它的一贯模式，不是临时起意（燧原科技持股>20%且是最大客户，是最成功的先例）。**但必须诚实指出：DeepSeek 这笔投资与燧原有一个根本区别——燧原是腾讯的供应商（2025年贡献其80%+收入），腾讯能实际影响它；而 DeepSeek 的架构明确排除了外部投资方的投票权。** 所以这笔投资**是好的财务投资，但不是可靠的战略护城河**。它改变的是腾讯的**资产端**（多了一笔可能IPO的股权），不是**竞争地位**。
>
> **对上期结论的修正**：上期报告"护城河（AI侧）"给出"入口强、模型弱"的结论——**这个结论本身不需要推翻，但"腾讯在AI模型上单线下注且落后"的隐含判断需要推翻。腾讯是双线下注。** 这使"AI期权"的**下行保护更强**（即使混元失败，腾讯仍持有赢家的股份），但**上行弹性更弱**（腾讯不会独占AI模型的价值）。

### 护城河趋势判断

**过去5年：显著变宽。** 证据：①毛利率从43%升至57.8%；②视频号从0到成为广告增长引擎；③小程序生态从工具升级为商业基础设施；④微信MAU从12亿升至13.85亿。

**未来5年：方向不变，但出现两个新变量。**

**变量一：AI 时代的护城河从"流量入口"变成"任务执行层"。** 传统护城河（社交关系链）依然牢固，但 AI Agent 时代的胜负手是"谁能把用户的意图变成已完成的任务"。腾讯的微信+小程序+支付是这个执行层最完整的候选，**但目前没有可验证的产品时间表**：
- 微信原生 AI 助手"**小微**"：6月起灰度测试。**截至10/8，仍未找到任何官方或可靠信源确认其上线/扩大测试时间表。** 花旗（9/27，目标价765港元）的推荐逻辑完全建立在对"小微"未来的推测上；
- **Handy Bot（市场传闻，腾讯未确认）**：9/30 有报道称腾讯正开发名为"Handy Bot"的 Personal Agent，**仍处内部测试**。**标注为未核实**；
- **QClaw 停运（9/24）**：腾讯版"龙虾"AI助手于 **12月24日起停止运营**，数据迁移至 WorkBuddy。**这是产品线收缩的信号。**

**变量二：护城河的"维护成本"在上升。** 传统上，腾讯的护城河是**低维护成本**的（社交网络自增强，边际成本趋零）。但在AI时代，维持同等竞争地位需要**每年约1,700亿人民币的资本开支 + 70亿美元的海外算力租赁**。**护城河本身没变窄，但"守卫它的成本"变了**——这直接压低自由现金流，进而压低估值中枢。

**本期新增的第三个视角（重要）：护城河可以被"买"一部分。**
腾讯通过持有 DeepSeek、燧原、Moonshot、MiniMax、智谱的股份，**在模型和算力两个环节上获得了"即使自己不做，也能分享赢家收益"的敞口**。这是一种**不同于传统护城河的"组合式风险对冲"**——它不保护腾讯的入口，但保护腾讯的**股东价值**。

> **必须同时指出反面**：**"股东价值被保护"不等于"公司护城河被保护"。** 如果 DeepSeek 的模型让用户不再需要微信，腾讯作为 DeepSeek 的少数股东获得的收益，**远小于它作为微信所有者损失的收益**。**这是两笔账，不能互相抵消。**

> 2. **硬件入口迁移**：如果交互迁移到手机之外的设备（眼镜、耳机、车载），微信的"手机第一屏"地位会被稀释。

> **这两者必须分开看**：AI分析置信度取决于**资料数量**，投资确定性取决于**生意本质**。**本期出现了一个罕见的反例：资料极多（A级），但AI仍然漏掉了最重要的事实（DeepSeek投资）。这说明"资料多"不仅不保证确定性，甚至可能因为强化既有叙事而降低判断质量。**
