## AI研究偏见自觉

**信息丰富度评级：A级（信息充裕）**

腾讯是全球市值前十的科技公司，上市超22年，券商覆盖超45家，中英文资料极丰富。属 A 级"信息充裕"。

**A级陷阱警示**：Q2财报后市场出现"财报明明超预期（营收2048亿 vs 一致预期2024-2028亿）股价却连跌两日"的现象（8月12日-1.95%、8月13日-2.56%）。这恰恰是 A 级研究最该警惕的**信息脱节**——AI 与市场共识都容易停留在"营收超预期=利好"，而真正定价的是**负自由现金流 + 资本开支 +176% + 净现金腰斩**。本报告重点回答：**市场为什么在"超预期"财报后抛售？抛售定价的是什么样的腾讯？**

**偏见自查**：
- [x] 我的"确定性"来自生意本质还是资料数量？→ 生意本质（微信生态、游戏、广告、毛利）是高确定性来源；AI 投入回报、2026-2027年资本开支节奏是低确定性来源。本报告明确分开标注
- [x] AI输出是否与市场共识高度雷同？→ "营收超预期、买入"是共识。本报告额外检验空方最新论点：**负FCF是否意味着印钞机熄火？资本开支2,000亿是否在摧毁股东回报机器？**
- [x] 信息优势在哪？→ ①用 8/13 实时汇率（1 RMB=1.164 HKD）重算估值；②对 Q2 财报中"负自由现金流"这一被多数标题党忽略的拐点信号完整拆解；③用工具验算所有关键指标
- [x] 如果把资料量减半，结论会变吗？→ 生意本质与估值区间结论不变；但"AI 投入是否划算"的判断把握度会显著下降——这是本版必须诚实的地方：**Q2 给了 AI 落地的强证据（WorkBuddy第一、Hy3全球前三、广告+22%），但资本开支的回报周期至少需要 2-3 年才能验证**

## 第二步：生意本质分析 — 段永平"对的生意"

### 一句话定义

**腾讯是中国数字生活的"操作系统"——微信14.39亿用户的超级入口连接社交、支付、游戏、广告、企业服务和AI，每一层都产生收入；现在它正把AI智能体（小微、元宝、WorkBuddy）接入这个税收系统。**

### 商业模式画布（Q2 2026数据更新）

| 维度 | 分析 |
|------|------|
| 收入类型 | 复合型：游戏内购（+11%重回双位）+ 广告（+22%加速）+ 支付佣金 + 云订阅 + **AI token付费（新增）** |
| 变现效率 | ARPU仍远低于Meta/字节；广告占比已升至21%，仍有巨大提升空间 |
| 核心资源 | 微信社交图谱 + 游戏IP矩阵 + 小程序生态 + **微信AI智能体"小微"入口（灰度中）** |
| **毛利率** | **58%创新高**——高毛利广告/游戏占比提升的结构性改善仍在继续 |

### 经营杠杆（Q2重要变化）

Non-IFRS经营利润：剔除新AI产品影响后**+19%至861亿**，而表观仅+9%——**核心印钞业务仍在以近20%速度增长，新AI产品（混元/元宝/WorkBuddy/CodeBuddy/小微）单季消耗105亿经营利润**。这是Q2最容易被误读的数字：**不是印钞机熄火了，而是利润被主动投入到AI中。**

### 段永平式追问

> **这门生意好在哪？**
>
> 好在它有两台发动机同时运转：(1) **核心业务印钞机**——游戏+广告+金融科技，Q2剔除AI投入后经营利润+19%，毛利率58%创新高；(2) **AI期权**——WorkBuddy办公智能体第一、CodeBuddy用户爆发、Hy3全球token消耗前三、小微灰度测试。坏在：**买入AI期权的成本是自由现金流转负、净现金腰斩、回购让位**。这门生意的"好"没有变，但"好"的价格计算方式变了——以前用"股息+回购"折现，现在必须计入2,000亿/年资本开支对每股价值的稀释。
>
> 段永平本人仍在用卖出看跌期权的方式逢低积累腾讯持仓（计划3-5年加到总股本1%），并在8月对泡泡玛特的期权履约引发市场关注——他理解"好生意也要经历回撤煎熬"。

### 关键区分与诚实标注

- **高置信度+高确定性**：生意质量、护城河、核心业务财务（Q2全部官方数据，多源0.00%偏差）
- **中等置信度+低确定性**：**AI投入回报**（本版新增核心不确定性）、监管、地缘政治、FCF能否转正
- **本次更新新增的诚实标注**：
  1. **自由现金流转负（-138亿）是本版最重要的信息增量**——但"剔除算力预付款后+376亿"说明FCF为负主要是AI预付款节奏，非经营恶化，需以Q3确认
  2. **净现金口径修正**：官方Q1净现金1,468.6亿（非8/3报告引用的902亿），本版采用官方口径；H1末582亿
  3. **归母权益/BVPS降级为估计**（QQ财经API资产负债表不可靠），PB 2.64x 需以中期报告官方数复核
  4. **8/3报告"回购恢复托底"逻辑需下修**：H1仅244亿港元（vs 2025年同期500亿+），AI资本开支正在系统性挤出回购
  5. **分析师目标价差异大**（花旗765 vs 摩根大通690），反映AI投入期观点分歧

**最终结论**：腾讯是一门确定性极高的好生意，由执行力极强的团队经营，目前正处在**从"股东回报期"切换到"AI投入期"的战略拐点**。Q2财报给出了AI落地的首批硬证据（WorkBuddy第一、Hy3全球前三、广告AI直接变现+22%），但代价是自由现金流首次转负、净现金腰斩、回购让位。市场在12.9倍PE（低于2021-2022监管底）已为AI投入的"失败情景"定价了大部分，但"失败情景"本身（利润停滞2-3年、回购消失、估值再杀30%）是真实存在的尾部风险。**投资者需要判断的核心问题从"你信不信任中国"变成了"你信不信任这笔2,000亿的AI投入能兑现"**——前者是信仰问题，后者是执行问题，而执行问题每季度都有财报检验。当前449.8港元处于合理买入区下沿，适合分批建仓，但必须接受：**这是验证期，不是丰收期；安全边际在估值（12.9x），不在现金流（FCF转负）**。
