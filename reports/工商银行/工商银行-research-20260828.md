## 第二步：生意本质分析 — 段永平"对的生意"

### 一句话定义

**工商银行是中国存款网络最庞大、客群最广泛的储蓄吸收器——通过全球最广的营业网点+对公结算系统+代发工资网络吸收居民和企业存款，转化为对公与个人贷款及债券投资，赚取利差，并承载国家信用担保。**

### 生意本质拆解

| 维度 | 分析 |
|------|------|
| 商业模式 | 典型**息差生意**：吸储（负债端）+放贷/投资（资产端）。全球总资产第一（57万亿），但不是平台型、非品牌消费品 |
| 收入结构 | 利息净收入占73.25%（2026H1），非息收入占26.75%并持续提升 |
| 复购/粘性 | **存款天然高粘性**——工资代发、养老金、企业结算，迁移成本极高 |
| 资本需求 | **重资本生意**：靠资本充足率约束扩张，ROE被杠杆+监管双重压制 |
| 经营杠杆 | 天然高经营杠杆：固定成本巨大（网点/人力/IT），营收小幅波动→利润大幅波动 |

### 5年盈利能力趋势

```
ROE：12.15% → 11.45% → 10.66% → 9.88% → 9.45% → 8.63%(2026H1年化)
净息差：2.11% → 1.92% → 1.61% → 1.42% → 1.28% → 1.29%(2026H1，首次回升)
归母净利：3,483 → 3,611 → 3,640 → 3,659 → 3,686亿（5年持续正增长，+5.8%累计）
```

**趋势解读**：净息差5年从2.11%跌至1.28%（累计-83BP，近腰斩），但归母净利润5年仍增长5.8%——靠**"以量补价"**（贷款规模从20.67万亿扩张至30.51万亿）+**资产质量改善**（不良率1.42%→1.31%）+**非息收入增长**对冲。**2026H1净息差首次环比回升至1.29%**，是2018年以来最重要的拐点信号。

### 段永平式追问

> **这门生意好在哪？**

好在**负债端全球无匹**——中国最大存款网络（37万亿存款）+最低的资金成本+国家信用，让工行能以极低成本吸收资金。这个负债端不是靠营销获得，而是靠**代发工资、养老金、政府/央企结算体系**天然沉淀，任何竞争对手都极难复制。

> **但另一方面（反面）**：这门生意的利润率被**监管定价（LPR/存款利率）、资本约束（核心一级资本充足率要求）、政治任务（普惠让利、制造业支持）**三重压制。ROE从12%降到8.6%是趋势而非意外。**"好生意"不等于"好投资"**——净息差企稳是边际改善，但绝对水平（1.29%）能否覆盖风险成本+资本成本存疑。重资本扩张每增加1万亿资产需要约120亿资本，形成"越增长越缺资本"的循环——这就是2026年3000亿特别国债注资的根本原因。

## 第三步：护城河评估 — 巴菲特"经济护城河"

### 五类护城河逐项验证

| 护城河类型 | 验证 | 评级 |
|-----------|------|------|
| **牌照/准入壁垒** | 全国性商业银行牌照极度稀缺，国有大行格局20年稳定 | ★★★★★ |
| **网络/网点效应** | 全球网点2.2万+，境内县域网络深，对公结算系统覆盖全国 | ★★★★★ |
| **转换成本** | 存款/贷款客户迁移成本极高（代发工资、企业结算、养老金体系） | ★★★★★ |
| **成本优势（负债端）** | 存款平均付息率1.36%（2025年，-36BP），全国最低资金成本之一 | ★★★★★ |
| **品牌/国家信用** | "宇宙行"+国家信用，破产风险趋近于零——最强隐性护城河 | ★★★★★ |

**数据支撑**：
- 2025年末存款37.31万亿，占全国居民存款比例约1/5，稳居全球第一
- 存款平均付息率1.36%（-36BP），利息支出下降11.9%快于利息收入下降6.7%
- 2025年制造业、普惠、科技创新贷款分别+19.4%、+22.8%、+19.9%——政策卡位

### 护城河趋势

**过去5年**：护城河**基本稳定**——网络、牌照、存款网络没有削弱；但数字化支付（支付宝/微信/数字人民币）正在侵蚀银行支付结算的中间环节，存款搬家到货币基金/理财的趋势延续。

**未来5年预判**：护城河**稳中略收窄**。净息差虽企稳但难有大幅回升；理财/基金对存款的分流持续；但工行的**负债端成本优势反而可能扩大**——因为利率越低，大行的低成本存款优势越凸显（小行负债成本更高，被迫退出竞争）。

### 巴菲特式追问

> **10年后这条护城河还在吗？什么能摧毁它？**

**还在**——10年后工行仍是中国最大银行、全球最大银行之一，存款网络+国家信用+牌照的组合10年维度极难被摧毁。巴菲特买银行最看重的是**负债端**，工行的负债端（存款成本1.36%）是全球大型银行中最好的之一。

**能摧毁它的**：①数字化彻底改变存款行为（存款从"网点粘性"变成"App价格战"，工行网点优势反而成成本负担）；②系统性资产危机（中国版1990s日本，地方债/地产链失控）；③息差低到覆盖不了风险成本（1%以下并持续）。三者均未发生，但①是5-10年真实威胁。

## 第四步：逆向思考与风险清单 — 芒格"反过来想"

### 工行可能失败的所有路径

| 失败路径 | 概率 | 影响程度 | 证据 |
|---------|------|---------|------|
| 净息差重新下行至1.2%以下 | 中（30%） | 高 | 2026H1企稳在1.29%，但存款重定价红利将逐步减弱（刘珺原话），LPR仍有下调压力 |
| 珠三角/区域资产质量恶化 | 中（25%） | 中高 | 珠三角不良率1.88%→1.98%（半年+10BP），个人不良率1.77%（+0.19pct），信用卡/经营贷压力 |
| 注资摊薄EPS | 高（已发生） | 中 | 3000亿特别国债（工行获大头），增发价预计0.7-0.8x PB，摊薄EPS约5-7%，核心一级资本充足率已降至13.21% |
| 房地产链/地方债风险 | 低-中（15%） | 高 | 个人住房贷款持续收缩，对公房地产敞口仍存 |
| 数字化转型落后 | 中（30%） | 中 | 工行IT投入领先同业（"工银智涌"600+场景），但金融脱媒趋势不可逆 |
| 利率市场化极端化 | 低（10%） | 高 | 存款利率下行空间已收窄（"存款利率下行的日子基本结束"），但若LPR再降 |

### 历史类比

**相似位置的历史公司**：
- **日本大银行（1990s）**：国家队、高存款、依赖息差。日本因资产泡沫+息差崩盘，PB长期0.3-0.5倍，20年不涨。**类比警示**：如果中国出现系统性资产问题，工行低估不是机会而是"价值陷阱"。
- **2008年美国花旗/富国**：大而不倒但估值崩80%。**国家信用担保≠股价不跌**。
- **积极类比**：富国银行1990s-2000s——依赖存款特许经营权+低成本负债，在低利率环境跑赢同行。工行当前的"低成本存款+高息差韧性"与富国有相似之处。

**与当前的区别**：中国银行资产质量指标（不良1.29%、拨备218%）处于历史最好水平；政府主动注资（3000亿特别国债）而非被动救助，说明**政策层在用"看得见的手"稳定银行体系**——区别于日本当年的被动。

### 空方核心论点

1. **无增长**：归母净利5年只涨5.8%，ROE从12%降至8.6%，重估逻辑的根基（ROE>10%）正在被侵蚀。
2. **注资摊薄**：3000亿注资摊薄EPS约5-7%，且暴露"内生资本不足"——留存70%利润仍不够扩张。
3. **息差绝对水平低**：1.29%的净息差在全球主要银行中偏低，一旦LPR再降或存款重定价红利消失，息差可能重回下行。
4. **估值已修复**：PB从0.5倍修复至0.73倍（A股），中特估逻辑已price in；股息率3.95%（A股）对险资吸引力下降。
5. **区域资产质量隐忧**：珠三角不良率上升至1.98%，信用卡/个人经营贷压力显现。
